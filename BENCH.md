# BENCH.md - run and compare

Generated by `training/bench/make_summary.py` from `docs/results/*.json`. Do not edit the
tables by hand: rerun the scripts. The repos' own accuracy claims were ignored; every
number here was measured on this machine (Intel i5-1230U, 16 GB RAM, no GPU, Windows 11,
Python 3.13).

Conditions to keep in mind when reading FPS figures: the machine was short of memory and
running the user's other applications during the bench, and several bench jobs overlapped.
Treat FPS as a lower bound.

## Hybrid plan

### Hybrid plan

_what we take, from where, and what we build_

| Task | We take | Why (measured above) | We build |
|---|---|---|---|
| Detection + tracking | Ultralytics YOLO11n (COCO) exported to OpenVINO, Ultralytics ByteTrack | OpenVINO roughly doubles nano FPS on this CPU; AGPL-3.0 licence is clear | Per-camera workers, shared model, detect-every-N, bags handled outside the tracker |
| Accident | Enos-123 YOLO11x accident weights (MIT), run on a side thread about once a second | Only accident weights with a licence. The unlicensed nano found more clips but also raised more false alarms | Vehicle-presence check on every model hit, trajectory rule as second opinion and fallback, persistence |
| Crowd | Nothing from the benched repos beyond the idea of counting people | Count rules flagged calm crowds and missed every dispersal on UMN | Temporal CNN on motion and occupancy features, trained on UMN, plus an overcrowding limit |
| Baggage | COCO bag classes from the shared detector; owner-proximity idea from the baggage repos | The logic in the benched repo is sound but starved by weak bag detection; the better bag weights have no licence | Position-based bag memory, owner assignment, owner-away timer, tracker-ID handover |
| Incident layer | Nothing | No benched repo merges cameras or explains severity | False-alarm filter, severity with reasons, cross-camera merge, operator feedback, evidence clips |

Unlicensed repos were benched and read, but no file or weight from them ships in this project.
