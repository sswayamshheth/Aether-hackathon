# BENCH.md - run and compare

Generated by `training/bench/make_summary.py` from `docs/results/*.json`. Do not edit the
tables by hand: rerun the scripts. The repos' own accuracy claims were ignored; every
number here was measured on this machine (Intel i5-1230U, 16 GB RAM, no GPU, Windows 11,
Python 3.13).

Conditions to keep in mind when reading FPS figures: the machine was short of memory and
running the user's other applications during the bench, and several bench jobs overlapped.
Treat FPS as a lower bound.

## Shared bench set (`data/bench/`)

| Task | Source | Clips | How they were picked | Ground truth | Licence note |
|---|---|---:|---|---|---|
| Accident | UCF-Crime, RoadAccidents | 8 | first 8 annotated test videos by number (001, 002, 004, 009, 010, 011, 012, 016), first 40 s of each | onset and end frame from the dataset's `Temporal_Anomaly_Annotation_for_Testing_Videos.txt` | research dataset (UCF CRCV); fetched from the Hugging Face mirror `AllenXeon/ucf_crime`, which labels it CC0-1.0 |
| Crowd | UMN Unusual Crowd Activity | 11 scenes (one video) | all scenes | per-frame label read from the "Abnormal Crowd Activity" caption burnt into the video; the caption rows are masked before any model sees a frame | University of Minnesota, research use; no licence text on the download page |
| Baggage | ABODA | 6 | videos 1, 2, 3, 4, 9, 10 (the shorter ones) | each video contains one abandoned-object event; no onset or box labels | GitHub `kevinlin311tw/ABODA`, no licence file |
| Normal | UCF-Crime, Testing_Normal | 4 | 006 (road), 015 (mall), 018 (airport hall), 024 (supermarket), first 40 s of each | no incident | as above |

Resolution is low (UCF-Crime and UMN are 320x240), which is typical of public CCTV
datasets and hard on every detector here.
